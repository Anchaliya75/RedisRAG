Databases are organized collections of structured data stored and accessed electronically. Relational databases use SQL to manage data in tables with rows and columns, enforcing relationships through foreign keys and constraints. NoSQL databases like Redis, MongoDB, and Cassandra offer flexible schemas for key-value, document, column-family, and graph data models. Choosing between SQL and NoSQL depends on data structure, scalability needs, and consistency requirements.

Vector search is a technique for finding similar items by comparing high-dimensional numerical representations called embeddings. These embeddings capture semantic meaning, allowing searches based on similarity rather than exact keyword matching. Algorithms like HNSW and IVF enable efficient approximate nearest neighbor search in large datasets. Vector search powers recommendation systems, semantic search engines, image retrieval, and retrieval-augmented generation for AI applications.

An operating system is software that manages computer hardware and provides services for application programs. The kernel handles process scheduling, memory management, file systems, and device drivers as core functions. Modern operating systems support multitasking, virtual memory, and user permission systems for security. Examples include Linux, macOS, and Windows, each designed for different use cases from servers to desktop computing.

Cryptography secures digital communication using mathematical algorithms to encrypt and decrypt information. Symmetric encryption algorithms like AES use a single shared key for both encryption and decryption. Asymmetric encryption uses public-private key pairs, enabling secure key exchange and digital signatures through algorithms like RSA and elliptic curve cryptography. Hash functions like SHA-256 create fixed-length digests for data integrity verification and password storage.

Distributed systems are collections of independent computers that work together to appear as a single coherent system. Key challenges include achieving consensus among nodes, handling network partitions, and maintaining data consistency. The CAP theorem states that a distributed system can provide at most two of three guarantees: consistency, availability, and partition tolerance. Technologies like Kubernetes, Apache Kafka, and distributed databases enable building scalable and resilient applications.

Cloud computing delivers computing resources including servers, storage, databases, networking, and software over the internet on demand. The three main service models are Infrastructure as a Service, Platform as a Service, and Software as a Service. Major providers include AWS, Azure, and Google Cloud, offering global infrastructure with pay-per-use pricing. Cloud computing enables organizations to scale resources dynamically, reduce infrastructure costs, and accelerate deployment of applications.
